## Runtime shared-library dependencies (368 deduped, via `ldd`)

Full list (source path + staged copy) is in `artifacts/manifest.json` ->
`artifacts.deps`, and copies are staged in `artifacts/deps/`. Breakdown by
origin:

| Source | Count |
|---|---|
| ROS2 core (rclcpp, rosidl typesupport/generators, rmw/FastRTPS, message packages) | 309 |
| OpenCV 4 (`libopencv_*.so`) | 56 |
| ZED SDK / CUDA (`libsl_zed.so`, CUDA runtime libs) | 3 |
| System libc/libstdc++ etc. | 0 (excluded — assumed present on any Linux target; see `package_artifacts.py`'s exclusion list) |

**Deployment implication**: if flashing/deploying to a fresh Jetson Orin Nano
image, the ROS2 Humble + OpenCV4 + ZED SDK 4.2.5/CUDA runtime environment
must already be installed system-side (matching versions) — `artifacts/deps/`
is a reference/backup copy, not a substitute for installing the real ROS2
Humble + ZED SDK on the target device.
